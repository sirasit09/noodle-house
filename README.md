# Noodle House

เว็บไซต์ตัวอย่างร้านขายบะหมี่กึ่งสำเร็จรูป ประกอบด้วยสินค้า 2 SKUs และตะกร้าสินค้าตัวอย่าง

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บไซต์
- `style.css` รูปแบบและการจัดวาง
- `script.js` ตะกร้าสินค้าและฟอร์มสั่งซื้อ (ตัวอย่าง ยังไม่เชื่อม Google Sheets)
- `images/` โฟลเดอร์สำหรับรูปภาพสินค้า

## วิธีเปิดดู
เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือ Deploy โปรเจกต์นี้ผ่าน Vercel

## หมายเหตุ
ข้อมูลลูกค้าที่แสดงในฟอร์มเป็นข้อมูลที่ผู้ใช้กรอก และคำสั่งซื้อยังไม่ถูกส่งไปบันทึกใน Google Sheets จนกว่าจะตั้งค่าการเชื่อมต่อในขั้นตอนถัดไป
